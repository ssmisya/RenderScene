## 阻塞验收的外部资料

需要两处原始、无遮挡、能确认拍摄日期的照片与尺度锚点。至少再补8张有效近期独立照片，并至少补一个独立拍摄来源；满足数量后仍须覆盖缺口，通常需要更多照片。

| 对象 | 必须补齐的取景 | 需要能看清 |
|---|---|---|
| 砖廊 | 正面、左右斜侧、背面、屋顶高位、台阶侧面、夜间同机位 | 各开间、柱截面、山花/檐口、坡道、扶手落点、附墙灯 |
| 菜市场 | 朝广场完整立面、圆角入口、左右侧面、屋顶、门组近景、夜景 | 两个入口各自位置、全部窗带/面板、店招、雨棚、显示屏安装状态 |
| 两处共同 | 街道连续全景、可识别定位点；至少一个已知宽/高或现场测量 | 建筑退界、路缘、灯柱和街道相互位置 |

原图尽量保留EXIF；作者明确拍摄日说明也可作为依据。不同年份/季节照片分别登记，不能将其拼成同一时点。仅有新资料仍不等于通过，随后必须继续返工、同机位逐图校验、重建并测试游戏包。
