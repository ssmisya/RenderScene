- 独立 Mac 应用通过 **16 / 16** 检查。新增棚廊登阶测试实际落脚点为 `(-62.51627, 1.030935, -37.5)`，能够从地面走到约 1.05 米高的平台。

- 本机 Apple M5 / Metal Forward+，窗口 1280×800。末段 5.35 秒 / 600 帧采样平均 112.2 FPS，帧时 p95 9.09 ms；这是短时采样，不是全地图长测。
- 游戏截图在 `renders/v2_2_1/game_*.png`；原生 Blender 成片在同目录 `DAY_*.png` / `NIGHT_*.png`。
- 测试报告内资产 SHA-256 与本次主工程 / GLB 一致，发布 ZIP 通过完整 CRC 检查。
